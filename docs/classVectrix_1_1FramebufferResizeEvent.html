Detailed Description

Sent when the window's framebuffer changed size, in pixels.

It is the size to give a viewport or an offscreen framebuffer matching the window. It differs from WindowResizeEvent's on a scaled display (HiDPI, Wayland scale factor).

Note
0x0 while the window is minimized. The renderer recreates its swap chain by itself
