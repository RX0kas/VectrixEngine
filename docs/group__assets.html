Definition Log.h:118

Load an asset into a variable, logging the reason when it fails.

A shorthand around AssetsManager::load for the common case where the failure only has to be reported. The variable is left untouched when the load does not work out.

Parameters
variableThe variable receiving the loaded asset
typeThe asset class to load, such as Texture or Mesh
pathThe path of the asset, relative to the assets folder
