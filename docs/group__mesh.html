bool Vectrix::loadOBJ ( const std::string & filepath,
std::vector< Vertex > & outVertices,
std::vector< uint32_t > & outIndices )
inline

Read a Wavefront OBJ file into vertices and indices.

Vertices repeated across faces are merged, so the same position, normal and texture coordinate triple is only stored once and referred to by index. A missing normal or texture coordinate becomes zero rather than failing the load.

Parameters
filepathThe path of the OBJ file to read
outVerticesReceives the vertices, appended to what is already there
outIndicesReceives the indices, appended to what is already there
Returns
true when the file could be read
