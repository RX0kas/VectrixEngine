Detailed Description

This function is the layer responsible for drawing Dear ImGui.

The Application creates it and keeps it as an overlay, so it draws on top of everything and gets the events first: the mouse and keyboard events ImGui wants don't reach the layers below (see startBlockEvents). Widgets registered through addWidget are rendered by this layer every frame.
