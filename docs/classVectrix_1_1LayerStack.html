Detailed Description

Holds the layers of the application, in the order they were pushed.

The stack is split in two groups: the layers, then the overlays above them. Updates and renders go from the bottom up (the layers in the order they were pushed, then the overlays), so what is pushed later draws on top; events go from the top down (the last overlay pushed first, the first layer pushed last), so what is on top can handle an event before what is under it. Names don't have to be unique.
