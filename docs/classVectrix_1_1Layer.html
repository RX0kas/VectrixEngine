Detailed Description

One slice of the application, receiving the update and render callbacks, and the events it subscribes to.

Derive from it and override only what is needed, every callback has an empty default. The layers are held by a LayerStack, which decides in what order they are called. A layer is an EventListener: it reacts to events by subscribing to them (see EventListener::subscribe), and only receives them while it is in the stack.
