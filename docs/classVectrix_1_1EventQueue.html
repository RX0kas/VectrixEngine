Detailed Description

Holds the events posted during a frame until they are sent, at the start of the next one.

The Application owns one: the window posts the input to it, and Application::postEvent posts there too. On the thread that created the queue (the main thread), the events are built in a buffer reused from frame to frame, so posting doesn't allocate once the buffer has grown to what a frame needs.

Any other thread can post too: its events are allocated apart, behind a lock, and sent after the main thread's ones. The order is kept per thread, not between threads.

Note
dispatch is main thread only
