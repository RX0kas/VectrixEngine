Detailed Description

Loads the assets of the project, and hands back the ones already loaded.

It sits above the per type managers and keeps a cache keyed on the resolved path, so asking twice for the same file gives back the same object rather than loading it again. The Application creates it, reach it through instance.

◆ getEngineAssetsPath()

std::filesystem::path Vectrix::AssetsManager::getEngineAssetsPath ( )
inlinestatic

Return the folder the engine's own built-in assets are taken from.

Used for assets that ship with the engine/editor itself (the ImGui shader, content browser icons, ...), never for project content, so it is not affected by setAssetsPath.

Returns
The engine's assets folder, as an absolute path
Note
Returned absolute so callers can join it with a sub-path and pass the result straight to load: load()'s relative-path handling would otherwise re-root a relative engine path under the project's assets folder (see setAssetsPath) instead of leaving it alone.
