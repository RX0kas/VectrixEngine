Detailed Description

A handle on one object of a Scene, and on the components it owns.

An entity is a lightweight handle rather than a container: it holds which scene it belongs to and an identifier, the components themselves live in the scene. Copying one is cheap and gives another handle on the same object. Build them with Scene::createEntity.
