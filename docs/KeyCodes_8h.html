Detailed Description

The key codes understood by Input::isKeyPressed and carried by the keyboard events.

The values match the ones GLFW uses, so a code coming from the windowing layer can be compared to a VC_KEY_* macro directly.

See also
Input::isKeyPressed
KeyPressedEvent::key
